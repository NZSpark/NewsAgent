# NewsAgent 微信报告输出功能任务分解

> 依据：`doc/output_wechat.md`  
> 目标：把微信报告输出功能拆解为可实施、可验收、可追踪的开发任务。  
> 状态：**部分实现**（2026-10-10）。协议相关部分被阻塞。
> 原则：先验证微信 iLink Bot 协议与现有报告接口，再实现核心能力；复用现有报告和 PDF；不依赖 Hermes/OpenClaw Gateway；不增加内部常驻调度器。

## 1. 项目目标与范围

### 1.1 最终交付目标

- [ ] NewsAgent 可通过二维码登录微信 iLink Bot。
- [ ] 用户可通过主动向 Bot 发送消息的方式，将自己的个人微信绑定为唯一收件人。
- [ ] 可独立执行微信登录、状态查询、收件人绑定、发送和退出登录命令。
- [ ] 支持摘要、完整报告文本、摘要加 PDF 三种发送模式。
- [ ] 默认使用摘要加 PDF 模式，并可由配置及命令行覆盖。
- [ ] 复用已经生成的摘要、正文和 PDF；微信发送模块不负责生成报告、重新提炼摘要或补生成 PDF。
- [ ] 默认发送最新报告，也允许手动指定单个报告文件。
- [ ] 支持现有 `news report` 命令显式附带微信发送功能，未指定发送选项时不改变原有行为。
- [ ] 支持系统调度器执行每日定时任务，包含报告生成后发送和直接发送已有报告两种方式。
- [ ] 发送失败时按默认策略最多重试 3 次，每次间隔 10 秒；这两个参数可在配置中修改。
- [ ] 支持发送状态、失败诊断、部分成功记录和定时任务的重复执行保护。
- [ ] 提供 macOS `launchd` 与 Linux `cron` 的模板及使用说明，由用户自行安装。
- [ ] 完成自动化测试、真实微信端到端测试、安全检查和许可证检查。

### 1.2 明确不做的事情

- 不支持微信群或多个收件人。
- 不要求运行 Hermes 或 OpenClaw Gateway。
- 不增加 NewsAgent 内部常驻调度器。
- 不自动安装、修改或卸载系统定时任务。
- 不在微信发送流程中生成报告、摘要或 PDF。
- 不默认重试认证错误、输入文件缺失等不可通过重试解决的问题。

## 2. 已确定的关键设计

| 项目 | 设计决定 |
| --- | --- |
| 微信实现 | 以 Hermes Python 微信实现为主要移植参考，OpenClaw 作为补充参考 |
| 接入协议 | 微信 iLink Bot，具体行为必须以实现时验证的协议版本为准 |
| 认证方式 | NewsAgent 内置二维码登录 |
| 凭据存储 | NewsAgent 独立配置目录，限制文件访问权限 |
| 收件人 | 单一固定个人微信 |
| 首次绑定 | 扫码成功后，目标微信主动向 Bot 发消息，程序保存收件人标识及协议所需上下文 |
| 调度方式 | 操作系统调度器 |
| 定时频率 | 每日固定时间，采用运行机器的本地时区 |
| 定时模板 | 提供模板和说明，由用户手工安装 |
| 全局默认发送模式 | `summary_pdf` |
| 定时默认模式 | 继承全局默认模式，允许单独覆盖 |
| 摘要来源 | 现有已生成报告中的摘要 |
| PDF 来源 | 现有已生成的 PDF |
| PDF 缺失 | 失败并记录，不补生成、不降级 |
| 手动报告选择 | 默认最新报告，也支持 `--file` 指定文件 |
| 组合模式文件参数 | 指定 PDF，由程序定位同一报告的摘要；摘要缺失则失败 |
| 重试默认值 | 最多重试 3 次，间隔 10 秒；首次发送不计入重试次数 |
| 报告生成失败 | 不发送本次消息，不回退到旧报告 |

## 8. 阶段 4：iLink 消息发送与三种模式

**验收：** 三种模式通过模拟客户端测试；文本和附件能够分别发送；输入不完整时不会静默降级；部分成功状态能被准确识别。

## 14. 关键技术规则与风险

### 14.1 重试并不自动保证恰好一次发送

网络超时可能发生在服务端已接收消息之后。重试可能造成重复发送。实现时优先使用协议提供的消息 ID、幂等键或状态查询能力；若接口不支持，必须在文档中说明该限制。

### 14.2 摘要与 PDF 发送不是原子事务

摘要消息和附件可能是独立请求。实现时分别记录状态；附件失败后不得无条件重复发送已确认成功的摘要。输入配对与存在性检查应尽可能在第一次网络发送前全部完成。

### 14.3 iLink 上下文不应被假定为永久有效

应确认协议令牌的有效期、更新与持久化条件。过期时返回明确错误，并指导用户重新建立会话。不得把模拟测试结果当作真实微信协议已经验证。

### 14.4 新 CLI 接口需要与实际项目一致

本任务文件列出的 `news wechat ...` 和新增参数是目标接口。编码前必须对齐现有 CLI 框架、参数命名、异常处理与退出码规则。

### 14.5 定时任务模板不负责安装

模板只提供可编辑配置和操作说明，用户自行安装。必须使用绝对路径并说明环境变量、工作目录、日志和本地时区规则。
