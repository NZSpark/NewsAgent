# AI News Agent

AI News Agent 旨在通过自动化流程抓取、筛选、总结最新 AI 资讯，生成每日简报 (Daily Briefing)。

## 设计方案

本项目采用了结合本地大语言模型与云端大语言模型的混合架构，以平衡成本、处理效率和输出质量。
